# Games — LLD Section

Turn-based rule engines. Best place to practice **boards**, **win rules**, and **Strategy** (dice / AI moves).

| Problem | Core skill |
|---------|------------|
| [Tic Tac Toe](./Tic-Tac-Toe/) | Grid, turns, win/draw |
| [Snake & Ladder](./Snake-And-Ladder/) | Teleports, exact finish, dice Strategy |
| [Chess](./Chess/) | Piece polymorphism, path clearing |

**Study tip:** Implement win/move validation on the board/piece — keep `Game` as orchestrator only.
