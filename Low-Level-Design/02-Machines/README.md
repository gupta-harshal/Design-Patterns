# Machines — LLD Section

Resource-constrained physical systems. Interview favorites because they force **state**, **assignment strategy**, and clear APIs.

| Problem | Core skill |
|---------|------------|
| [Parking Lot](./Parking-Lot/) | Spot fit policy, tickets, fee Strategy |
| [Elevator](./Elevator/) | Directional scheduling (SCAN-like) |
| [Vending Machine](./Vending-Machine/) | State pattern transitions |
| [ATM](./ATM/) | Auth flow + cash denomination chain |

**Study tip:** Draw the state diagram *before* classes for Elevator / Vending / ATM.
