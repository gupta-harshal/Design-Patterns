# Low-Level Design (LLD)

This folder is a dedicated space for **system-style Low-Level Design** problems — object models, class diagrams, flows, and working Java sketches for interview-style machine designs (games engines, booking flows, parking lots, etc.).

Unlike the GoF pattern modules next door, each problem here focuses on **end-to-end design of a small system**: requirements → classes → interactions → extensibility.

## How each problem is structured

* **`details.md`** — Requirements, class design, diagrams, sequence flows, and design decisions
* **`Main.java`** — Runnable Java sketch that mirrors the LLD
